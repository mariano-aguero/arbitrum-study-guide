# 1.2 — Solidity, ABI & Contract Lifecycle

> **TL;DR:** Solidity compiles to EVM bytecode plus an ABI that tells the world how to call it. Deployed code is immutable — upgrades need proxies. Don't reinvent tokens or access control: use OpenZeppelin, follow Checks-Effects-Interactions, and most classic exploits disappear.

## Solidity at a Glance

```solidity
contract Vault {
    address public owner;          // state → storage slot 0

    modifier onlyOwner() {
        require(msg.sender == owner, "not owner");
        _;                          // function body runs here
    }

    function withdraw(uint256 amount) external onlyOwner { ... }
}
```

- **Visibility:** `public` (anyone + internal), `external` (only from outside, cheaper for large args), `internal` (this + children), `private` (this contract only). *Nothing is secret on-chain — `private` only restricts code access, not readability.*
- **Modifiers** wrap functions with reusable pre/post conditions (`onlyOwner`, `nonReentrant`).
- **Storage layout:** state variables live in 32-byte slots, in declaration order. Adjacent variables smaller than 32 bytes get **packed** into one slot — order your declarations to save gas (`uint128, uint128, uint256` = 2 slots; `uint128, uint256, uint128` = 3).

## ABI, Selectors & Calldata

The **ABI** is the contract's public interface: it defines how function calls and arguments are encoded into bytes.

- **Selector** = first 4 bytes of `keccak256("transfer(address,uint256)")` → `0xa9059cbb`.
- **Calldata** = `selector + arguments`, each argument padded to 32 bytes. Dynamic types (strings, arrays) are encoded as offset pointers.
- Practical uses: decoding raw calldata when debugging failed txs, and gas — every non-zero calldata byte costs 16 gas (4 for zero bytes).
- In Solidity: `abi.encode` (padded), `abi.encodePacked` (compact — beware hash collisions), `abi.decode`.

## Contract Lifecycle

1. **Compile** — `solc` produces **bytecode** (what gets deployed) + **ABI** (how to call it).
2. **Deploy** — a tx with empty `to` field; the constructor runs once and the *runtime* bytecode is stored at a new address.
3. **Call** — two ways: **transactions** (write, cost gas, need a signature) vs **`eth_call`** (read, free, no state change).
4. **Upgrade** — deployed code is **immutable**. Upgradeability = a **proxy** that holds the state and `delegatecall`s a swappable implementation:
   - **Transparent proxy** — upgrade logic lives in the proxy; simple, slightly costlier per call.
   - **UUPS** — upgrade logic lives in the implementation; cheaper, but forgetting it bricks the contract.
   - ⚠️ Implementations must keep the same **storage layout** across versions (never reorder/remove variables) or state gets corrupted.

## Token Standards

| Standard | What it is | Typical use |
|---|---|---|
| **ERC-20** | Fungible tokens (`transfer`, `approve`, `balanceOf`) | Currencies, governance, staking |
| **ERC-721** | Non-fungible, one unique `tokenId` per asset | NFTs, positions (e.g. Uniswap V3 LP) |
| **ERC-1155** | Multi-token: fungible + NFT in one contract, batch ops | Gaming, editions |

Never write these from scratch — inherit from [OpenZeppelin Contracts](https://docs.openzeppelin.com/contracts) (audited, battle-tested):

```solidity
contract MyToken is ERC20, Ownable {
    constructor() ERC20("MyToken", "MTK") Ownable(msg.sender) {}
}
```

## Common Security Pitfalls

- **Reentrancy** — an external call lets the callee re-enter before your state updates (The DAO hack). Defense: **Checks-Effects-Interactions** (update state *before* external calls) + `ReentrancyGuard`.
- **Overflow/underflow** — since Solidity **0.8**, arithmetic reverts on overflow by default; only `unchecked {}` blocks can wrap. Pre-0.8 code needed SafeMath.
- **Access control** — any `public`/`external` function without a guard is callable by *anyone* (Parity wallet hack). Use OpenZeppelin `Ownable` (single admin) or `AccessControl` (roles).
- Honorable mentions: don't use `tx.origin` for auth, don't rely on `block.timestamp` for randomness, check return values of low-level calls.
